# Contributing to Iris

## Pull requests

To open a pull request, use the `create-pr` agent skill: in Claude Code, type `/create-pr`.
It merges the target branch into yours, runs the checks, writes the description from the
PR template and checks it against the PR policy before opening the PR. See
[docs/guides/create-pr.md](docs/guides/create-pr.md) for what it asks, how it behaves and
the one-time setup (`gh`, the `project` scope, repository access).
